# Code of conduct

## The short version

Be decent. Assume the other person is doing their best with incomplete information,
because in an issue tracker everyone always is.

## What's expected

- Treat people with respect, including when you think they're wrong.
- Critique code and ideas, not people.
- Accept that maintainers may decline a change that doesn't fit the project's
  constraints. "No" isn't hostility.
- Remember that many users here are researchers, not developers. A question that seems
  basic to you is not a waste of anyone's time.

## What isn't acceptable

Harassment, personal attacks, discriminatory language, sexualised content, deliberate
intimidation, sustained disruption, publishing someone's private information, or
posting real respondent data belonging to someone else.

## Scope

This applies in issues, pull requests, discussions, commit messages, and anywhere else
someone is representing the project.

## Enforcement

Report a problem privately to the maintainers via GitHub. Reports are handled
confidentially. Responses range from a warning to a permanent ban, depending on
severity and pattern.
