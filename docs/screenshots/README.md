## Before you add one

- **Use fake data.** No real respondent answers, no real names.
- **No `/exec` URL**, not even partially — it's an unauthenticated write endpoint.
- Check the questionnaire title and description on screen. They end up on a public
  page that prospective users, collaborators and funders will read.
- Shoot at roughly 360–400 px wide (phone width) so the images stay legible inline.
